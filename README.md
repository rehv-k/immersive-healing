# Immersive Healing

박물관 실감영상관의 압도적 시청각 경험을 웹 브라우저에서. 어두운 복도를 걸어 들어가면 입구를 제외한 타원 홀의 벽 전체가 하나의 하늘과 바다로 이어지고, 그 빛이 바닥까지 비친다. 골든아워에서 별이 뜨는 밤, 새벽까지 10분의 순환 속에서 원하는 만큼 머무는 1인칭 몰입 전시.

설치도 가입도 없는 정적 웹. 1호 콘텐츠 「일몰」 MVP.

> 힐링(이완·휴식)을 목적으로 하는 경험이며 치료·치유 효능을 주장하지 않는다. 이 원칙은 UI 문구 검수 항목(PRD FR-90 / TC-UI-01)으로 강제된다.

## 경험

| 단계 | 무엇이 일어나는가 |
|---|---|
| 게이트 | 편안한 관람 2택(보통/민감함), 헤드폰·멀미 사전 고지. 클릭 한 번이 오디오와 시점 잠금을 함께 연다 |
| 복도 | 어둠 속에서 소리가 먼저 도착한다. 파도는 앞쪽에서 들리고, 그쪽이 홀이다 |
| 홀 | 타원(15×11m, 둘레 ≈82m) 벽 전체가 이음매 없는 리본 스크린. 바닥·천장이 그 하늘을 반사한다 |
| 순환 | 10분 주기로 골든아워 → 일몰 → 블루아워 → 별밤 → 새벽. 끝과 시작이 이어져 이음매가 없다 |

앰비언스 5레이어는 태양 고도를 따라 섞이고(밤이 낮보다 커지지 않는다), 정위 음원 5개는 벽면 앵커에 놓여 보이는 것과 들리는 방향이 맞는다.

## 실행

```bash
npm install
npm run dev    # http://localhost:5173   (?debug 로 측정 오버레이)
```

- 데스크톱 Chrome / Edge / Firefox (Pointer Lock 필요). 모바일은 unsupported 화면으로 안내한다.
- 조작 — 이동 `WASD`/방향키 · 시점 마우스 또는 `Q E R F` · 일시정지 `Esc` · 음소거 `M`

하늘은 기본적으로 **절차 셰이더**로 그린다. 영상 파이프라인(A/B 루프 스왑·렌디션 전환)까지 확인하려면 합성 렌디션을 만든 뒤 `?video`로 접속한다.

```bash
npm run gen:media   # 로컬 테스트용 합성 렌디션 생성 (FFmpeg 포함, 최초 1회)
```

## 설계

세 계층이 단방향으로만 이야기한다. `ui/`는 store에 **액션만** 발행하고 `scene/`·`audio/`를 import하지 않는다. `scene/`·`audio/`는 관측값을 `sys.*`로만 발행한다. 상태 전이와 설정 write는 `core/` 전유이고, Pointer Lock·Fullscreen·visibility API는 `core/inputSession.ts` 한 곳만 만진다. rAF 루프는 `main.ts`가 유일하게 소유한다.

이 규칙들은 문서에만 있지 않고 **빌드 게이트가 기계적으로 강제한다** — 금지된 import, `core` 밖의 상태 write, 전유 API 유출, 발행처 없는 데드 액션은 전부 빌드를 깬다(`scripts/check-arch.mjs`).

```
src/
  core/     상태 머신(6상태·8전이) · 설정 클램프 · 입력 세션
  scene/    타원 홀 기하 · 하늘 순환 · 해석적 반사 · 렌더러 · 품질 적응
  audio/    3단 게인 버스 · 앰비언스 합성 · 위상 믹스 · 정위 음원
  ui/       DOM 오버레이 (게이트 · 일시정지 · 설정 · 크레딧 · HUD)
```

선택·판정·히스테리시스 같은 순수 로직은 DOM·three 비의존 함수로 분리해 시험 대상으로 만든다.

**스택**: TypeScript(strict) · Vite · three.js 0.185.1(정확 핀 — postprocessing peer 제약) · postprocessing · Web Audio(자체 GainNode 버스). 프레임워크·상태 라이브러리·오디오 라이브러리 없음. 프로덕션 번들 **gzip ≤300KB**.

몇몇 결정은 성능 근거로 되돌리지 않기로 못박혀 있다 — 반사는 미러 카메라가 아니라 뷰 광선의 해석적 교차로 구해 **추가 렌더 패스 0**, 탭 전환 시 오디오는 `suspend()`가 아니라 게인 페이드(복귀 시 스케줄이 어긋나므로), 루프는 `<video loop>`가 아니라 A/B 스왑. 근거는 `docs/SDD.md`와 `CLAUDE.md` §7에 있다.

## 검증

```bash
npm test        # 단위 시험 — 순수 함수만 (설정 클램프 · 전이 매트릭스 전수 · 렌디션 선택 · 적응 히스테리시스 · 홀 기하 · 하늘 순환 · 위상 믹스)
npm run report  # TC 커버리지 리포트 → docs/report/ci-report.md
npm run build   # typecheck + build + 번들 예산 + 라이선스 허용목록 + 아키텍처 규칙 + TC 리포트
```

시험 제목의 `[TC-<모듈>-NN]` 태그가 `docs/tc/` 시험 문서와 자동 대조된다. 문서에 정의되지 않은 태그(orphan)가 하나라도 있으면 빌드가 실패한다 — "이 코드가 어떤 요구를 지키는가"에 번호로 답하지 못하는 시험은 통과로 치지 않는다는 뜻이다.

## 문서

```
GOAL → MRD → RFP(v1.3) → PRD(v1.2) → SRS(v1.4) → TC(docs/tc/)
```

구현 규범은 **SRS**, 시험 권위는 **TC 문서**, `docs/report/ci-report.md`는 특정 실행의 evidence일 뿐이다. 요구·시험 ID는 append-only — 재배치·재사용하지 않고 폐기는 취소선과 대체 포인터로 남긴다. 설계 결정은 `docs/SDD.md`, 적대 감사는 `docs/audit/`, 그날의 기록과 미결 항목은 `docs/dev/DEVLOG.md`에 있다.

AI 협업 컨텍스트는 `CLAUDE.md`와 `.claude/skills/`(5종)에 정리돼 있다.

## 현재 상태

**v5 몰입 홀 구현 완료** — 타원 연속 리본 스크린, 해석적 반사 바닥·천장, 10분 하늘 순환, 위상 연동 앰비언스, 선택형 호흡 리듬 빛(기본 off), 품질 자동 적응, comfort 세트, 감각 안전 규칙(전환 페이드 ≥0.5초, 섬광 없음).

다음은 **M0a 성능 실측**(반사 셰이더 비용 포함) → **M1 아트 디렉션**이다.

미디어와 앰비언스는 아직 로컬 개발용 합성본이다. 실제 일몰 영상·사운드 소스 선정과 하한 실기 확보는 `docs/dev/DEVLOG.md`의 사용자 확인 항목에 있다.
