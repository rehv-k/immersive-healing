## 1. 테스트 전략

- **1.1 레벨**: 정적 검사(check-arch — 액션 발행 경계) + 문구·마크업 검사 + 실기 시연(포커스·접근성).
- **1.2 SRS 추적성**: §6 표. 순수 로직 분리 시 시험 레인 승격, **7번부터** 발급.

## 4. 테스트 실행 순서

검사(TC-UI-01·02·04·05)는 빌드·리뷰 시점. 시연(TC-UI-03·05·06)은 릴리스 전 체크리스트.

## 5. Pass/Fail 기준

검사 = 위반 0 기록. 시연 = 절차 기록에 기대 결과 충족 명기. 필수 SRS 연계 TC 100% Pass가 합격 조건.
